\section{Purpose}

To make every number in this paper traceable, we document the mapping between experiment batches, protocols, and inclusion status. All values in this paper derive exclusively from batches marked \textbf{authoritative}; \textbf{excluded} batches are retained in the repository and in \texttt{canonical\_results\_v2.csv} (with explicit suffix annotations) for provenance only.

\section{Audit Scripts}

The 115-directory KIBA audit, the parameter-count architecture check (GIN 498,177 / GAT 521,345), and the config-level assertions applied to every included run are implemented in the public repository scripts:
\begin{itemize}
\item \texttt{p0\_1\_1\_kiba\_audit.py} -- KIBA directory audit
\item \texttt{p0\_1\_2\_kiba\_deep\_audit.py} -- Deep config-level audit
\item \texttt{e5\_1\_t11\_t4\_config\_audit.py} -- Cold-target experiment config audit
\end{itemize}

\section{Metric Convention}

All CI values across authoritative batches use the \textbf{pair-counting convention} (standard pairwise counting method for Concordance Index). This ensures consistency with the main text and enables direct comparison across experiments.

\section{Data Availability}

All experimental data, including excluded batches with explicit annotations, are available in the public repository at \url{https://github.com/rxp613-dev/contrastive-dta} and archived at \url{https://doi.org/10.5281/zenodo.23308152}.
