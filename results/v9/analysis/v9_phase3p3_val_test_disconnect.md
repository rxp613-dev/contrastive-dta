## 结论（数据驱动，区分成立与不成立的部分）

- **成立——尺度与分布脱节**：cold-both 划分的 validation 实体全部来自 train（warm），test 完全 cold；test MSE 最高达 val 的 35×。在 warm-val 上做 early stopping 与 checkpoint 选择，优化的是一个与测试不同分布、不同尺度的量。
- **成立——OOD 下选点退化**：真 scaffold 划分上 9/10 个 run 选在 epoch 1–21，warm-val 在 OOD 下几乎没有信号。
- **不作为强声称——α 排名脱节**：GAT cold-target α 扫描上 val/test 排名 ρ=0.85，反而不低于 GIN standard 的 0.89；选点遗憾两批均仅 1–2%。故“val/test α 排名在 cold 下系统性反转”不被数据支持，论文不做此声称。
- 因此：① 冷启动 E0 vs E7 配对对比（p=0.99）必须与"选点机制在 cold/OOD 下失效"并列披露，不能把其数字直接读作 CL 的冷启动效应；② 方法建议：cold/scaffold 评估应使用实体同样不重叠的 validation（cold validation）或改用固定预算/固定 epoch 报告。
- 旧"18×"提法保留为保守描述（实测 18.5–35×），并以本节三组真实证据替代原单一数字。
